Sort Stash is a Door Dash credit optimizer for Chase Sapphire® Credit Cards currently in very early development. Currently testing backend before porting over to JavaScript. Finished Chrome extension will allow users to add all convenience store items to a "master" cart that will then sort into individual $10, $10, $15 carts per Sapphire card.
